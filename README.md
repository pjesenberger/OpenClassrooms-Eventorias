# Eventorias

Event app: sign in, browse, search and sort events, create events with a photo and see them on a map.

**Stack:** Swift, SwiftUI, Firebase Auth, Firestore, MapKit, PhotosUI, XCTest

**Setup:** add your own `GoogleService-Info.plist`, and copy `Eventorias/Configuration/Secret.example.plist` to `Secret.plist` with your imgbb API key.
